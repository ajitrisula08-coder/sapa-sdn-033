# Masjid Darussalam — hasil build (GitHub Pages)

Folder ini berisi hasil build aplikasi dari `masjid-darussalam/` (branch pengembangan).
Jangan diedit langsung. Untuk memperbarui: jalankan `npm run build:pages` di folder
`masjid-darussalam`, lalu salin isi `pages-dist/` ke folder ini.
